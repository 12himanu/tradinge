# API Specification

## 1. Conventions

- **Base path:** `/api/v1`. JSON everywhere except uploads (multipart).
- **Auth:** Sanctum SPA cookie. Call `GET /sanctum/csrf-cookie` first, then `POST /api/v1/auth/login`; send `X-XSRF-TOKEN` on mutating requests. CORS is limited to the frontend origin.
- **Envelope:** resources wrap in `{"data": …}`; lists are paginated as `{"data": [...], "links": {...}, "meta": {...}}` (Laravel defaults).
- **Errors:** `{"error": {"code": "NOT_A_CHART", "message": "…", "details": {}}}`. Validation errors use Laravel's 422 format: `{"message": "…", "errors": {"field": ["…"]}}`.
- **IDs:** ULIDs for charts, analyses, predictions and trades. **Times:** ISO 8601 UTC. **Prices:** JSON numbers, max 4 dp.
- **Authorization:** users only ever see their own resources (policies on every route; 404, not 403, for other users' ids).
- **Rate limits:** upload 20/min, analyze 10/min, others 120/min per user. 429 responses include `Retry-After`.
- **OpenAPI:** generated by Scramble at `/docs/api`, and used to generate the frontend TypeScript types.

## 3. Endpoint details

### 3.1 `POST /charts/upload`

Multipart fields:

| Field | Rules |
|-------|-------|
| `image` | required; file; MIME `image/png`, `image/jpeg`, `image/webp` (sniffed); ≤ 10 MB; 600×400 to 8000×8000 px |
| `symbol` | optional; string ≤ 20; uppercased |
| `exchange` | optional; exists in `exchanges.code`; default is the user's exchange |
| `timeframe` | optional; one of `15m`, `1h`, `4h`, `1D`, `1W` |
| `trading_style` | required; `swing`, `positional`, `investing`, `intraday` |
| `position_status` | optional; `none` (default) or `holding` |
| `position_entry_price`, `position_quantity` | required if holding; > 0 |
| `thesis` | optional; ≤ 2000 chars |
| `auto_analyze` | optional; boolean |

**201 Created**
```json
{
  "data": {
    "id": "01J8Z3K4QW9X2Y7T5V6B1N0M3C",
    "status": "uploaded",
    "declared": {"symbol": "HDL", "exchange": "NEPSE", "timeframe": "1D", "trading_style": "swing"},
    "stock": {"id": 42, "symbol": "HDL", "name": "Himalayan Distillery Limited"},
    "image": {"url": "/api/v1/charts/01J8Z3K4QW9X2Y7T5V6B1N0M3C/image", "width": 1920, "height": 1080, "size_bytes": 482113},
    "deduplicated": false,
    "analysis": null,
    "created_at": "2026-09-12T08:15:02Z"
  }
}
```
If the same image already exists for this user, the response is **200** with the existing upload and `"deduplicated": true`. With `auto_analyze`, `analysis` contains the queued analysis summary.

Errors: 413 (too large), 415 (unsupported type), 422 (validation or dimensions), 429.

### 3.2 `POST /charts/{id}/analyze`

```json
{
  "trading_style": "swing",
  "timeframe": "1D",
  "symbol": "HDL",
  "position_status": "none",
  "thesis": "Breakout above 580 looks close",
  "force": false
}
```
Every field is optional and overrides the upload's declared values; the corrected symbol is used for one-click re-runs.

| Status | When |
|--------|------|
| **202 Accepted** | Queued: `{"data": {"id": "01J8Z3…", "status": "queued", "status_url": "/api/v1/analysis/01J8Z3…/status"}}` |
| 200 OK | A completed analysis with identical inputs and the same engine version exists and `force` is false. Returns it with `"reused": true` |
| 409 Conflict | An analysis for this upload is already queued or running (`ANALYSIS_IN_PROGRESS`) |
| 404 / 422 / 429 | Not found / invalid overrides / rate limit |

### 3.3 `GET /analysis/{id}/status`
```json
{"data": {"id": "01J8Z3…", "status": "running", "stage": "vision", "progress": 35,
          "message": "Reading price axis", "updated_at": "2026-09-12T08:15:41Z"}}
```
Stages: `queued` → `preprocess` → `vision` → `data` → `analysis` → `scoring` → `narrative` → `guardrails` → `persisting` → terminal (`completed`, `partial`, `failed`, `cancelled`).

### 3.5 `GET /history`
Query parameters: `symbol`, `exchange`, `decision`, `bias`, `data_tier`, `status`, `from`, `to`, `sort` (`-created_at` by default), `page`, `per_page` (≤ 100). Returns `AnalysisSummary` items: id, stock, timeframe, style, decision, bias, setup score, tier, prediction status roll-up, thumbnail URL, created_at.

### 3.6 `POST /trades`
```json
{
  "stock_id": 42,
  "analysis_id": "01J8Z3…",
  "prediction_id": "01J8Z4…",
  "side": "long",
  "status": "open",
  "entry_date": "2026-09-13",
  "entry_price": 551.0,
  "quantity": 160,
  "stop_loss": 520.0,
  "target_price": 620.0,
  "strategy": "pullback",
  "reason": "Pullback into order block with RSI holding 50",
  "tags": ["smc", "ob_retest"],
  "confidence_level": 3
}
```
Validation: for `long`, `stop_loss < entry_price < target_price` when both are present; `side = short` is rejected when the exchange disallows short selling; `entry_date` is not in the future for `open` trades. Returns **201** with a `TradeResource` including computed `risk_pct`, `planned_rr` and `planned_risk_amount`.

### 3.7 `POST /trades/{id}/close`
`{"exit_date": "2026-09-25", "exit_price": 604.0, "exit_reason": "manual", "fees": null, "followed_plan": false, "lessons": "Exited before T1 on a red day"}`
When `fees` is null, they're computed from the exchange fee schedule. The response includes net P&L, return %, R multiple and the **plan vs execution** block (entry slippage, stop honored, exit vs T1).

### 3.8 `POST /predictions/{id}/outcome` (manual resolution)
`{"result": "win", "exit_price": 621.0, "exit_at": "2026-09-20T00:00:00Z", "notes": "No CSV for this symbol; checked chart manually"}` → sets `evaluation_method = manual`. Rejected (409) if the prediction was already auto-resolved.

### 3.9 `GET /stats/calibration`

Query: `engine_version` (defaults to the user's newest), `scope` (`global` or `style:<swing|positional|intraday|investing>`).

```json
{"data": {
  "engine_version": "0.1.0+cfg.abc", "scope": "global", "method": "binned",
  "sample_size": 84, "active": true, "min_bucket_sample": 30,
  "brier_score": 0.231, "brier_score_calibrated": 0.208, "calibration_error": 0.12,
  "buckets": [
    {"bucket": "70-79", "low": 70, "high": 79, "n": 34, "wins": 20,
     "predicted": 0.74, "observed": 0.5882, "interval": {"low": 0.42, "high": 0.74},
     "support": 34, "calibrated": 0.5882, "qualified": true}
  ],
  "engine_versions": ["0.1.0+cfg.abc"]
}}
```

`predicted` is the mean setup score in the band; `observed` is the share that reached T1 before the stop. `calibrated` is `null` until the band (or, under `isotonic`, the pooled block behind it — that is what `support` reports) holds `min_bucket_sample` resolved outcomes. `method` is `binned` below 200 resolved setups and `isotonic` above. Curves are never pooled across engine versions or users.

## 4. Internal AI engine API (FastAPI)

Reachable only on the compose network, or on localhost in dev. Every request carries:
- `X-Request-Id`: the analysis ULID
- `X-Timestamp`: Unix seconds
- `X-Signature`: `hex(HMAC-SHA256(secret, timestamp + "." + body))`, rejected outside ±300 s

### 4.1 `POST /v1/analyze`
```json
{
  "analysis_id": "01J8Z3…",
  "image": {"path": "charts/1/2026/09/01J8Z3K4QW9X2Y7T5V6B1N0M3C.png", "sha256": "9f2c…"},
  "declared": {"symbol": "HDL", "exchange": "NEPSE", "timeframe": "1D"},
  "symbol_universe": ["HDL", "NABIL", "NTC", "UPPER", "…"],
  "trading_style": "swing",
  "position": {"status": "none"},
  "account": {"size": 500000, "currency": "NPR", "risk_pct": 1.0, "max_position_pct": 25.0},
  "market": {"exchange": "NEPSE", "allows_short": false, "tick_size": 0.1, "lot_size": 1,
             "trading_days": [7, 1, 2, 3, 4], "fees": {"...": "from exchanges.fee_schedule"}},
  "ohlcv": {"timeframe": "1D", "source": "csv",
            "bars": [["2025-09-01", 512.0, 520.5, 508.1, 518.0, 12450]]},
  "historical_context": {"similar_setups": []},
  "user_thesis": "Breakout above 580 looks close",
  "options": {"model_profile": "gpu_8gb", "language": "en"}
}
```
*(Market values come from configuration; `ohlcv` is omitted when no bars exist.)*

**Response:** `200`, `Content-Type: application/x-ndjson`, one JSON object per line:
```
{"type":"progress","stage":"preprocess","progress":5}
{"type":"progress","stage":"vision","progress":20,"message":"Reading price axis"}
{"type":"warning","code":"SYMBOL_CONFLICT","message":"Declared HDL; header reads HDL.N","details":{}}
{"type":"progress","stage":"narrative","progress":70}
{"type":"result","payload":{ "...AnalysisResult..." }}
```
or a terminal `{"type":"error","code":"MODEL_UNAVAILABLE","message":"…","retryable":false}`.

`AnalysisResult` contains `chart_context`, `data` (tier, quality, as_of, bars_used), `evidence[]`, `indicators[]`, `patterns[]`, `levels[]`, `factors`, `setup_score`, `bias`, `scenarios[]`, `trade_plans[]`, `decision`, `predictions[]` (specs), `report`, `report_markdown`, `narrative_source`, `warnings[]`, `versions`, `timings_ms`. It's defined by `contracts/analysis_result.schema.json`.

Pre-stream errors: `401` (bad signature), `422` (invalid request), `503` with `Retry-After` (engine busy: the concurrency semaphore is full). The engine cancels work if the client disconnects.
